POE Part 2 – QuickChat

Project Description

QuickChat is a Java application that allows users to send, store, and manage messages. The project demonstrates the use of Java programming concepts, including classes, methods, loops, and conditional statements.

Features

- Send messages to recipients.
- Validate message details.
- Store and manage messages.
- Display message information.

Technologies Used

- Java
- IntelliJ IDEA
